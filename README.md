# Visualise probability distributions of LLMs

Uses python 3.12.


# IF windows
```
python -m venv venv
source venv/Scripts/activate
python.exe -m pip install --upgrade pip
pip install -r requirements.txt
./web.sh
```

# IF mac 
```
python -m venv venv
source venv/bin/activate
python.exe -m pip install --upgrade pip
pip install -r requirements.txt
./web.sh
```




Then open index.html in a browser.
